# Tracking Hub (Web)

Multi-shop order tracking dashboard. Companion to the **Order Tracker Hub** Chrome extension.

## Stack

- React + TypeScript + Vite + Tailwind
- Shop switcher UI ready for multiple Etsy accounts
- Hosted free on **GitHub Pages**
- Planned: Firebase Auth / Firestore / Functions (phone + extension can share the same API later)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` deploy via GitHub Actions to GitHub Pages:

`https://engrsyednaqvi.github.io/tracking-hub-webapp/`
